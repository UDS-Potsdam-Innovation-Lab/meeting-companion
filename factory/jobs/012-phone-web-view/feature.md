Local phone web view (split from 010-voice-profiles, part a): a locked-down local web view the desktop app serves to phones in the same room, opened via a QR code. One local network interface only, per-meeting token (>= 128 bit), closes when the feature is turned off, recording stops or the meeting ends; negative tests for wrong/old/foreign tokens, CSRF, DNS rebinding, oversized/malformed requests, rate limit (429). Includes the "closed" phone page. Stack: axum 0.8 on Tauri's tokio runtime, qrcodegen for an SVG QR code in the core. Reused by Voice profiles (010) and later Team review (frame 08). See factory/jobs/010-voice-profiles/spec.md (AC2) for the full requirements.
